## Why I built Clipboard

I wanted a straightforward way to find and reuse text I had copied earlier. The standard clipboard only keeps the latest item, which meant I often had to go back to the original source and copy something again.

I built Clipboard to solve that problem. It keeps a searchable history of copied text, so I can find what I need, pin useful entries, and copy them again without interrupting what I am doing.

I wanted the app to stay focused: a clean interface, practical features, and local storage. Clipboard is designed for text, and in this build, its history stays on the Mac rather than being sent to a cloud service.

## What it does

- **Keeps a clipboard history** — captures copied text and displays it in one place.
- **Searches past clips** — find an entry by searching its text.
- **Pins important entries** — keep frequently used text at the top of the list.
- **Copies with a click** — send any saved entry back to the clipboard.
- **Manages history** — delete individual entries, clear recent clips, or clear the full history.
- **Supports light, dark, and system appearance** — choose the look that suits your Mac.
- **Stores data locally** — clipboard history is stored on the Mac.

## Built with

I built Clipboard using:

- [Tauri](https://tauri.app/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Rust](https://www.rust-lang.org/)

## Run it locally

To work with the source code, you will need Node.js, npm, and the Rust toolchain installed.

```bash
git clone https://github.com/amir-dev-projects/clipboard.git
cd clipboard
npm install
```

Run the app in development mode:

```bash
npm run tauri dev
```

Build a macOS application:

```bash
npm run tauri build
```

The build output is generated by Tauri under `src-tauri/target/release/bundle/`.

## Project status

Clipboard is a personal project that I am building and improving over time. The current version focuses on a reliable, local clipboard history for text. Features such as cloud sync are not part of this build.
